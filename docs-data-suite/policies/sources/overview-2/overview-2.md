## What are Sources

1. Click on the Policies tab. By default, the system will navigate to the Sources subtab.
2. Click on the Edit button to the right of the any configured source.
3. ![This image has an empty alt attribute; its file name is image-16-1024x331.png](images/image-16-1024x331.png)Inside the Edit Source pop-up box, edit the previously configured File System fields.
4. ![](images/image-69.png)Once the sections within the Edit source pop-up box are updated, select the Validate button. Ensure that the validation is successful.
5. Click OK.
6. ![](images/image-71.png)Click on the Save All Changes button. Once clicked, a pop-up box will appear requesting to confirm all changes.
7. Click OK to confirm the saved changes.

![](images/image-24-1024x364.png)

## Delete

1. Click on the Policies tab. By default, the system will navigate to the Sources subtab.
2. Click on the Delete button to the right of the an configured source. Once selected, the corresponding source will disappear from the subtab.
3. ![This image has an empty alt attribute; its file name is image-16-1024x331.png](images/image-16-1024x331.png)Click on the Save All Changes button. Once clicked, a pop-up box will appear requesting to confirm all changes.
4. ![](images/image-29-1024x383.png)Click **OK**
