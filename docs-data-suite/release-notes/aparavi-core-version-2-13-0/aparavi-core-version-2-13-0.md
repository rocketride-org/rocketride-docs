Introducing this release brings substantial business benefits to the Legal Services, AI Industry and IT industry sectors. The go-to-market strategy for Aparavi in collaboration with Relativity provides a distinct advantage for professionals in Legal services. By integrating APARAVI’s data intelligence capabilities with Relativity, individuals in the legal field can optimize their workflow, leveraging the power of data intelligence to enhance productivity. This integration not only saves valuable time for experts but also alleviates the challenges associated with dealing with irrelevant data, contributing to a more efficient and stress-free work environment.

 
### Aparavi for Legal Services enriching Relativity Server 2023

This release enhances our Relativity server Integration to the latest Relativity Server version as well. Now, APARAVI has a universal Relativity Connector that supports 2022 and 2023 versions. This Integration together with Relativity has several benefits in the Legal industry:

- **Streamlined Data Focus:**
    - Aparavi ensures a more focused approach to handling data, allowing legal professionals to concentrate on essential tasks by eliminating irrelevant information from extensive datasets.
- **Metadata and Classification Integration:**
    - Seamless integration with Relativity enriches the platform with valuable metadata, classification hits, and context fields, facilitating quick identification of sensitive data such as Personally Identifiable Information (PII) within documents.
- **Efficient Document Review in Relativity:**
    - Relativity highlights classification hits and contexts, significantly accelerating the manual review process. This not only reduces errors but also provides users with compelling evidence embedded within their documents.
- **Queryable Classifications for E-Discovery:**
    - Aparavi delivers both pre-built and customized classifications to Relativity, enhancing its e-discovery capabilities. Users can now extract valuable insights efficiently during the e-discovery process using these queryable classifications.

### Text Extraction Connector

- **New Connector for Data Extraction:** With the latest Data Action Transform, APARAVI introduces a new connector designed to extract and organize raw text data from a variety of documents. This functionality streamlines the process of data extraction, empowering businesses to unlock valuable insights from their documents effortlessly.
- **Seamless Integration with Business Applications and AI Tools:** The new connector seamlessly integrates extracted data into different business applications and AI tools, enhancing productivity and enabling informed decision-making. Now, businesses can leverage pertinent information extracted from documents to drive innovation and gain a competitive edge.
- **SMB File Share :** Furthermore, the extracted text data is conveniently provided into an SMB file share location, ensuring easy access and utilization within existing infrastructure. This integration simplifies the data management process, allowing businesses to efficiently leverage the extracted data for various purposes.
- **Unlocking Valuable Insights:** By offering the capability to extract raw text data from scanned documents across different services, APARAVI's latest update revolutionizes the realm of data extraction. Businesses can now uncover crucial insights from their documents, fueling growth and success.


### Data Ownership and Permissions from Outlook

In this release, file data owners and permissions from Microsoft Outlook (Emails) are gathered. Aparavi gathers file ownership and permissions, irrespective of their location. This file ownership is gathered from Outlook, establishing a robust foundation for maintaining data integrity and security across enterprises. The gathered data on ownership and permissions aligns with our strategic vision, ensuring that users, with diverse identities, could perform any functionality within Aparavi like Data Actions, conducting file Discovery, engaging in Semantic searches, and leveraging Question and Answer capabilities—all within their designated user level access.
