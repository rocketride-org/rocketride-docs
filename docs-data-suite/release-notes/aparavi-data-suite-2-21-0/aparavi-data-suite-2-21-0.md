title: "Aparavi Data Suite 2.21.0"
date: 2025-03-22
---

This release marks the official launch of the product, introducing structured tiers to facilitate partner purchases of feature-specific bundles tailored to customer needs.

The **APARAVI Data Suite** now includes three tiers, each defining an expanded feature set:

- **Baseline**: Know the volume of your unstructured data. Explore, discover, and classify your unstructured data with the baseline kit and gain better outcomes with better data insights.
- **Advanced**: Generate powerful pre-set or custom reports, gain actionable insights, and automate critical business data movement across a wide range of target services
- **Ultimate**: A complete solution for data curation and transformation—create embeddings with support for various Vector DBs, diverse embedding models, and flexible chunking strategies. Includes semantic search, OCR, and seamless third-party integrations via access to API
