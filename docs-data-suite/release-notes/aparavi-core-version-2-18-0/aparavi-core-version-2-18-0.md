In this release, we’ve emphasized optimizing APARAVI for **Mac-Intel** chipset users and developers, ensuring a streamlined experience from installation to usage.

Here are the key improvements and features introduced in this release for Mac users:

#### **Seamless Installation for Mac Users**

- **Simple Download Process**: Mac users can now easily download the APARAVI installer directly from our website, with clear instructions tailored to MacOS environments. The download and setup process has been optimized for speed, allowing users to get started in a matter of minutes.
- **Reduced Setup Time**: We've drastically reduced the number of steps needed to install APARAVI on a Mac, ensuring that users can have the product installed and running in under **10** minutes. This accelerated setup process means you can connect your data sources almost immediately and start gaining insights from your data with minimal hassle.
- **Product Features**: All APARAVI-supported features, including advanced AI functionalities(Semantic search, Milvus Integration), are fully available and seamlessly integrated for Mac users.
- Supported OS Versions in this release: [Pre-requisites for the All-in-one installer](https://aparavi-software.helpscoutdocs.com/article/502-pre-requisites-for-mac-os-all-in-one-installer?preview=6723606dd0576266aafb76cf)

**Improvisations on the Tagging functionality that use Analytic Service**

In previous versions, there was a limitation where newly created or deleted tags were not immediately reflected in the Analytics service. With this release, that issue has been resolved, allowing users to manage document tags seamlessly.

Now, when users create or delete tags, the changes are immediately recognized by the Analytics service. This means:

- **Easier Tagging**: Users can quickly create tags and have those tags instantly available for tagging and discovery.
- **Efficient Tag Management**: When tags are deleted, the associated documents are automatically untagged, ensuring accurate and up-to-date data management.

This fix enhances the overall tagging experience, making document discovery and organization more efficient.
