## Copy Data Action Decommissioned

The Copy Data Action has been decommissioned from the product. This reflects our commitment to aligning with user needs. After recognizing that the encrypted data format associated with this action was not well-received by end-users, we have decommissioned the Copy data action.

## Core Scans are faster!

Splitting up the Permissions as a separate toggle to enable, enhances the efficiency of our Core scan. By default, these permissions are disabled, allowing for Core Scan operations. Importantly, the Permissions toggle operates independently, avoiding any dependencies that might hinder the activation of indexing or classifications scan options.
