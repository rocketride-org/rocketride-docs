## **Purpose**

Aparavi format is a propriety format, purpose built for our platform. It enables our software to leverage unparalleled levels of data intelligence while encrypting, compressing, and segment your data for optimal efficiencies and security.

## **Encryption**

Aparavi format utilizes AES-256 encryption to protect your stored data. This encryption technology can be configured with a unique passphrase that you have sole control over.

## **Compression**

Quickly and effectively compress, we leverage the LZ4 compression algorithm to optimize storage and save you space/money. Compression ratios will depend based on the type of file formats.

## **Segmentation**

Breaks down data into 256k chunks, ideal for data transfers.
